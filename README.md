# HealNest

This repository contains the migrated HealNest application.

- `frontend/` — Next.js, React, JavaScript, and Tailwind CSS
- `backend/` — Node.js + Express + PostgreSQL API
- `heal_nest/HealNest/` — the original Laravel source, intentionally left untouched

Copy each `.env.example` file to a local `.env` before running the app and provide environment-specific values.
